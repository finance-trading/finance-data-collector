# Four-Layer Screening Rules v0

> 状态：**PROVISIONAL / RESEARCH ONLY**  
> 生效日期：2026-09-27  
> 适用策略：Quality Company + Temporary Problem + Mispricing  
> 目的：明确每一次筛选到底在筛什么，防止把 `Quality PASS`、`核心观察池`、`事件触发`和`可以买入`混为一谈。

## 1. 四层漏斗总览

| 层级 | 核心问题 | 输入 | 输出 | 当前状态 |
|---|---|---|---|---|
| Layer 1：Universe Eligibility | 这家公司是否适合用普通经营公司的统一口径比较？ | 当前 S&P 500 成分股快照 | 普通公司候选集 / 专用模型池 / 数据不可用 | 已用于当前截面；成员来源非官方、非 PIT |
| Layer 2：Mechanical Quality | 事件发生前的五年数字是否达到最低质量门槛？ | Layer 1 普通公司候选集 | `PASS_COMPLETE` / `PASS_REVIEW_REQUIRED` / `FAIL` | v0 已运行，得到 96 家初筛通过公司 |
| Layer 3：Core Watchlist Fit | 我们是否能够长期理解、监控并证伪这家公司？ | Layer 2 通过公司 | 核心观察池 / 储备池 / 仅保留在宽研究池 | 评分卡从本文件开始使用；现有 23 家仍为 provisional |
| Layer 4：Event & Investment Gate | 本次下跌是否真的是“暂时问题 + 错误定价”？ | 通过质量门槛的公司及一次具体事件 | `BUY_CANDIDATE` / `WATCH` / `AVOID` / `BLOCKED` | 流程已确定；部分数值门槛仍待正式批准 |

四层必须按顺序通过。后层不能反向修改前层规则；尤其不能因为喜欢某家公司、股票跌得很多或事后已经恢复，就放宽事件前的质量门槛。

---

## 2. Layer 1：Universe Eligibility

### 2.1 目标

这一层只判断“能否使用同一套普通经营公司口径比较”，不判断公司好坏，也不判断估值。

### 2.2 当前纳入规则

1. 使用日期为 2026-09-23 的当前 S&P 500 成分股快照；
2. 以 SEC CIK 作为公司身份，同一家公司多个证券代码合并：503 个证券代码合并为 500 家公司；
3. 必须能够映射到 SEC CIK 和 Company Facts；
4. 普通公司统一筛选暂时排除 GICS `Financials`、`Real Estate` 和 `Utilities`；
5. 被排除行业进入 `SEPARATE_MODEL`，不记为质量 `FAIL`。

排除原因是银行、保险、REIT 和公用事业的监管资本、准备金、杠杆和资本开支含义不同，不能用普通公司的 FCF、ROA 和 Net Debt / FCF 直接横比。

### 2.3 输出状态

- `ELIGIBLE_ORDINARY`：进入 Layer 2；
- `SEPARATE_MODEL`：需要行业专用质量模型；
- `UNAVAILABLE`：无法确认公司身份或取得必要 SEC 数据；
- `OUT_OF_UNIVERSE`：不属于本次指定 universe。

### 2.4 证据边界

当前成员名单来自二手当前快照，不是 S&P DJI 官方授权文件，也不是历史 Point-in-Time 成分股数据。因此它可以用于当前研究池建设，不能直接用于无幸存者偏差的历史回测。

## 3. Layer 2：Mechanical Quality

### 3.1 目标

用事件发生前已经存在的数字，排除长期现金流、盈利质量、增长、稀释或杠杆明显不达标的公司。这里筛的是“事前质量基础”，不是预测公司会不会从本次下跌中恢复。

### 3.2 数据窗口和基础定义

- 当前截面窗口：SEC Frames `CY2021–CY2025`；
- `FCF = CFO - CapEx`；
- `FCF Margin = FCF / Revenue`；
- Revenue CAGR 和 Diluted Share CAGR 使用窗口内最早、最晚可比观察值；
- Net Debt / FCF 使用最新可比年度；净现金公司可以出现负值；
- 中位数指标使用窗口内可比年度值；
- 正式事件研究必须改用事件时点可见的 PIT 数据，不能用后来重述的数据替代。

### 3.3 八个同时满足的机械门槛

1. 至少有 **4 个可比年度**；
2. FCF 至少 **4/5 年为正**；
3. 五年中位 ROA **≥ 5%**；
4. 五年中位 FCF Margin **≥ 4%**；
5. 五年中位 Operating Margin **≥ 8%**；
6. Revenue CAGR **严格 > 0%**；
7. Diluted Share CAGR **≤ 3%**；
8. 最新 Net Debt / FCF **≤ 4.0x**。

当前 500 家解析公司中有 96 家满足 v0 机械公式。

### 3.4 缺失值规则

当前工作簿允许 Diluted Share CAGR 或 Net Debt / FCF 缺失的公司暂时保留，但必须标记 `PASS_REVIEW_REQUIRED`。这是为了避免把 XBRL tag 缺失误判成基本面失败，不代表允许带着缺口投资。

进入 Layer 4 前执行 fail-closed：两个字段都必须通过 10-K / Company Facts 复核并满足阈值，否则不得成为 `BUY_CANDIDATE`。

截至当前版本，LULU、MDLZ、PG、CSX 因 Net Debt / FCF 缺失而处于 `PASS_REVIEW_REQUIRED`。

### 3.5 输出状态

- `PASS_COMPLETE`：八项门槛通过，关键字段完整；
- `PASS_REVIEW_REQUIRED`：公式暂时通过，但至少一个关键字段缺失；
- `FAIL`：至少一项硬门槛失败；
- `DATA_CONFLICT`：拆股、并购、财年错位或 tag 冲突使指标不可解释；先复核，不得擅自按 PASS 或 FAIL 处理；
- `UNAVAILABLE`：证据不足，不能计算。

`PASS` 的含义仅为“值得继续研究”；它不等于好价格、不等于 Temporary Problem，更不等于买入。

## 4. Layer 3：Core Watchlist Fit

### 4.1 目标

从 Layer 2 通过公司中选择少量能够在事件发生前长期覆盖的公司。这里筛的不是“谁的历史财务数字最好”，而是“谁最适合由我们持续形成可证伪判断”。

### 4.2 六项评分卡

每项按 `0 / 1 / 2` 分评分，总分 12 分。Founder 与晓飞先独立评分，再讨论；原始分数不得覆盖。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 能力圈 | 无法清楚解释客户、产品和盈利方式 | 能解释主要业务，但关键环节依赖外部专家 | 能清楚解释客户为何购买、公司如何赚钱及主要失败路径 |
| 付费必要性 | 需求偏可选，付费动机弱或主要靠补贴 / 流量 | 有真实需求，但替代方案较多或定价权一般 | 产品关键、ROI 清楚，客户持续付费理由强 |
| 黏性 / 竞争优势可测量 | 只存在抽象“护城河”叙事 | 有部分留存、份额、网络或成本优势证据 | 黏性来源明确，并有可持续跟踪的 KPI |
| Temporary / Structural 可证伪性 | 无法预先写出区分标准 | 能写出方向，但缺少明确时间和指标 | 能在事件前写出指标、阈值、时间窗和反证条件 |
| KPI 与证据可获得性 | 关键经营数据长期不可获得 | 主要依赖管理层定性披露或低频数据 | SEC、IR 或可靠经营数据能够连续追踪核心假设 |
| 覆盖效率 | 业务过于复杂，无法在现有资源下持续更新 | 可以覆盖，但需要较多专门知识或拆分 | 一页正常状态 dossier 能抓住主要价值驱动，季度更新可维护 |

### 4.3 核心观察池准入规则

同时满足以下条件，才具有核心池资格：

1. Layer 2 为 `PASS_COMPLETE`；`PASS_REVIEW_REQUIRED` 只能进入储备池；
2. 两位评分者的独立总分都 **≥ 9/12**；
3. “能力圈”“Temporary / Structural 可证伪性”“KPI 与证据可获得性”三项，任何一位评分者都不得给 0 分；
4. 两人总分差超过 2 分，或任何单项相差 2 分时，必须 Red Team；无法消除的重大分歧进入储备池；
5. 完成一页式正常状态 dossier，包括价值驱动、核心 KPI、正常利润率 / 再投资率、资本配置、结构性风险、事件触发器和正常估值区间；
6. 核心池以 **15–30 家**为容量上限，不因凑数量降低绝对门槛。

如果合格公司超过 30 家，按以下顺序决定优先覆盖：

1. 两人平均总分更高；
2. “可证伪性 + KPI 可获得性”小计更高；
3. 证据更完整、更新成本更低；
4. 能降低现有核心池共享风险主题集中度；
5. 仍相同则保留在储备池，不依靠主观偏好强行升级。

### 4.4 输出状态

- `CORE_WATCHLIST`：核心观察池，持续覆盖；
- `RESERVE`：质量通过，但证据、评分分歧、dossier 或容量条件尚未满足；
- `BROAD_RESEARCH_ONLY`：保留在宽研究池，用于记录事件和增加预测样本，不承担持续深度覆盖；
- `REMOVE_FROM_CORE`：后续证据显示已不满足核心池规则，但保留历史记录。

当前 23 家名单是在这张评分卡冻结前人工选出的，因此仍标记为 `PROVISIONAL`。必须把 96 家全部按同一评分卡重新评分后，才能把 23 家改称正式核心观察池。

## 5. Layer 4：Event & Investment Gate

### 5.1 目标

判断一次具体下跌是否同时满足：问题更可能是暂时性的、长期经济价值损失小于价格损失、估值提供足够补偿。每个事件单独判断；公司曾经通过 Quality Gate 不会永久获得买入资格。

### 5.2 事件进入研究的条件

以下任一公司特定事件可以进入研究：业绩 Miss、Guidance 下调、产品延期、一次性成本、管理层问题、监管事件、客户流失、CapEx 激增、新竞争者或行业短期下行。

机械对照组使用已经冻结的价格规则：

> 事件前已属于机械 Quality Universe，发生公司特定事件后相对所属行业回撤至少 25%，机械买入并持有 12 个月。

该规则只用于衡量主动判断的附加值，不自动授权实盘买入。主动研究可以记录未达到 -25% 的事件，但必须注明其不是机械基线样本；主动事件触发窗口和较宽阈值尚未冻结。

### 5.3 研究完成条件

Founder 与晓飞必须在讨论前分别冻结：

- Temporary / Structural 概率；
- 未来 3–5 年长期盈利能力变化；
- 事件对收入、利润率和 FCF 的影响；
- Bear / Base / Bull Fair Value；
- 市场隐含的悲观假设；
- 与市场的具体分歧；
- 证伪条件和预计验证时间；
- 初步建议：Buy / Watch / Avoid。

任何字段缺失，事件只能是 `WATCH` 或 `BLOCKED`。

### 5.4 `BUY_CANDIDATE` 的九个硬条件

1. 事件发生前已经通过当时版本的 Layer 2，且当前证据状态为 `PASS_COMPLETE`；
2. 原则上来自 Layer 3 核心观察池；非核心公司必须先补完同等深度 dossier，并说明为何没有在下跌后临时扩大能力圈；
3. 已识别导致下跌的具体事件和市场担忧，不能只有“跌了很多”；
4. 两人已经完成独立判断、Red Team 和原始记录冻结；
5. 讨论后的 Temporary 概率达到正式门槛，且长期竞争力未发生根本变化；
6. 已用事件后信息重做 Bear / Base / Bull 估值，不能使用历史高点或事件前价格作为 Fair Value；
7. Base Case upside 约 **30% 或更高**；
8. Bear Case 损失可承受，Risk / Reward 达到正式门槛；
9. 无关键证据缺口，且加入后不突破单一持仓、行业和共享风险主题上限。

其中第 7 项已作为 Opportunity Screen 使用，不是止盈规则。第 5、8、9 项涉及的 Temporary 概率、最大 Bear Case 损失、最低 Risk / Reward 和组合上限尚未获得正式批准，因此当前最多形成 `PROVISIONAL_BUY_CANDIDATE`，不能把这份 v0 描述为完整实盘授权规则。

### 5.5 硬性否决条件

出现以下任一情况，不得买入：

- Quality 结论依赖事件发生后的解释，而不是事件前证据；
- 问题已经更可能是结构性的，或关键结构风险无法量化；
- 估值依赖“回到以前股价”；
- 只有价格下跌，没有长期 earning power 和现金流分析；
- SEC / IR / 经营证据存在未解决矛盾或阻断项；
- 买入理由无法写出可观察的证伪条件；
- 组合中的同一风险主题已经超过上限。

### 5.6 输出状态

- `PROVISIONAL_BUY_CANDIDATE`：已满足当前已冻结条件，但仍等待未定数值门槛批准；
- `WATCH`：研究已启动，但价格、证据或风险收益尚不够；
- `AVOID`：更可能是结构性恶化，或估值没有补偿风险；
- `BLOCKED`：关键数据、证据或独立判断不完整；
- `NO_ACTION`：不满足事件条件。

## 6. 每层不得回答的问题

| 层级 | 可以回答 | 不可以回答 |
|---|---|---|
| Layer 1 | 能否使用统一口径研究 | 公司是不是高质量 |
| Layer 2 | 历史数字是否达到最低质量门槛 | 当前问题是不是暂时、股票是否便宜 |
| Layer 3 | 团队能否事前理解并持续监控 | 本次下跌是否应该买 |
| Layer 4 | 本次事件下是否存在可执行错价 | 策略长期是否已经被证明有效 |

## 7. 版本与变更纪律

1. 每次修改阈值必须产生新版本，记录日期、理由和受影响公司数；
2. 不允许针对单一公司回改阈值；
3. 原始评分、事件判断和估值快照只能追加版本，不能覆盖；
4. 当前截面筛选与历史 PIT 回测分开保存；
5. `UNAVAILABLE`、`DATA_CONFLICT` 和 `BLOCKED` 必须保留，不能为了得到结论而填充假数据；
6. Layer 3 评分卡正式生效前，应由两人对全部 96 家盲评；
7. Layer 4 的未定数值门槛经书面确认后，再升级为 v1 实盘规则。
