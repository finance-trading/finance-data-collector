# AI 产业链公司漏斗 v0

> 状态：**PROVISIONAL / RESEARCH ONLY**
> 生效日期：2026-10-30
> 适用范围：`data/ai_companies.json` 全部 234 家 AI 产业链公司（6 条产业链层 × 32 个细分环节）
> 目的：把 234 家全量公司压成分层漏斗，让每家公司在**自己所在产业链层内**有明确的研究深度、更新频率与触发价格带，并支持**自动分档 + 人工覆盖**的日常维护。

这份漏斗回答的是「**该花多少精力覆盖哪家公司**」，不是「该不该买」。买入授权仍由 [`four-layer-screening-rules-v0.md`](four-layer-screening-rules-v0.md) 的 Layer 2–4 决定。

---

## 1. 漏斗结构

- 6 条产业链层各自独立成漏斗：`power / silicon / infra / model / app / edge`。
- 层内按**市值**自动分 3 档；**不跨层比市值**，所以一条电力小盘不会因一条软件大盘而被挤到底部。
- 每档绑定一个研究深度、一个更新频率、一个触发价格带。

| 层 id | 层名称 | 公司数 |
|---|---|---|
| `power` | 能源与电力 | 20 |
| `silicon` | 芯片与半导体 | 56 |
| `infra` | 算力基础设施与云 | 42 |
| `model` | 模型与数据平台 | 9 |
| `app` | AI 软件与应用 | 94 |
| `edge` | 终端与具身智能 | 13 |

## 2. 三档定义

档位只决定**覆盖深度**，不授权买入。

| 档位 | 定位 | 自动分档（层内市值） | 研究深度 | 更新频率 | 价格触发带 | 对应动作 |
|---|---|---|---|---|---|---|
| **T1 核心** | 层内不可替代 / 生态核心 | 前 20%（至少 1 家） | 完整 dossier：业务拆解、5 年财务、KPI、竞争格局、估值区间、证伪条件 | 每周 + 事件后 24h | 回撤 ≥15% 启动事件研究；≥25% 且质量未坏进入行动候选 | 可进入 Layer 4 事件研究 |
| **T2 重要** | 层内重要参与者 | 20%–50% | 一页公司卡片 + 季度财报跟踪 | 每月 + 财报后 | 回撤 ≥20% 启动研究，研究后决定是否升 T1 | 研究后决定是否升级 |
| **T3 观察** | 层内其余公司 | 后 50% | 仅价格 / 市值 / 关键新闻扫描，不做独立估值 | 每季度 | 回撤 ≥30% 升级审视，无独立行动资格 | 无独立行动资格 |

规则说明：

- **自动分档**：层内市值降序；前 20% → T1，20%–50% → T2，其余 → T3。市值缺失排在最后；市值相同的按代码排序保证稳定。每层至少 1 家 T1，≥2 家的层还至少 1 家 T2。
- **市值是重要性的自动代理**。真正重要但市值偏小的公司（如 EDA、光互连、电力温控）用人工覆盖提档，见第 4 节。

## 3. 股价区间口径

价格**不决定档位**（档位只看重要性 / 市值），价格只决定**何时启动研究 / 行动**：

- 展示字段：当前价、市值、日涨跌、**52 周回撤**、**52 周分位**、52 周高 / 52 周低。
- 52 周高 / 低由 `change_52w_pct`（高点回撤）与 `rise_52w_pct`（低点涨幅）反推：`高 = 价 / (1 + 回撤/100)`，`低 = 价 / (1 + 涨幅/100)`；退化区间（新高==新低）标记为 `—`。
- 每档触发带 = 距 52 周高点回撤百分比，见上表。回撤进入触发带 → 进入「触发研究」，记录到每日变化。
- 触发带是**观察提示**，不是买入信号；是否行动仍过 Layer 2–4。

## 4. 人工覆盖（`config/funnel_overrides.json`）

- 格式：`"TICKER": {"tier": 1|2|3, "note": "原因"}`；`tier` 必须是 1/2/3。
- 覆盖值**优先于自动档位**；`note` 记录原因，供月度复核。
- `_` 开头的键是说明，被忽略。
- 治理纪律：
  1. 每次覆盖必须写 `note`；
  2. 覆盖只应因**重要性**（生态位置、不可替代性）而非**看好价格**；
  3. 每月复核一次，理由失效即删除；
  4. 不在这里新增公司（新增改 `data/ai_companies.json`，跑 `fdc.ai_layers` 校验）。

示例：

```json
{"CDNS": {"tier": 1, "note": "EDA 双寡头，生态核心"}}
```

## 5. 日常维护

```bash
# 每日：刷新报价 + 重算漏斗 + 打印当日变化
uv run python -m fdc.quotes
uv run python -m fdc.funnel

# 只看告警（行情过旧 / 缺价时非零退出，适合定时任务）
uv run python -m fdc.funnel --check
```

或一键（含网络抓取，失败即停）：

```bash
bash scripts/update_funnel.sh
```

产出：

- `data/generated/funnel.json` — 机器快照，次日用于 diff；
- `outputs/ai-funnel/ai-chain-company-funnel.xlsx` — 5 个 sheet：漏斗定义 / 分层汇总 / 公司表（234 行，可筛选）/ 人工覆盖 / 每日变化；
- `outputs/ai-funnel/daily-changes.csv` — 当日变化日志。

每日需人工过一遍的内容：

1. **档位变化**（市值跨线）与**自动档位变化**（临界调整）；
2. **触发研究**（进入价格触发带）→ 按档位启动相应研究；
3. **缺报价**（新股 / 停牌）→ 排查是否需移出 universe；
4. 有人覆盖争议时，两人各写 `note`，月度复核。

每周 / 每月节奏：

- 每周：更新全部 T1 的 dossier；
- 每月：刷新 T2 卡片 + 复核人工覆盖；
- 每季：扫描 T3，把连续命中触发带的公司提档到 T2。

## 6. 与四层筛选的关系

| 本漏斗（覆盖优先级） | 四层筛选（买入授权） |
|---|---|
| 决定「研究多少家、研究多深、看哪几层」 | 决定「这一次下跌该不该买」 |
| 档位升降只看重要性 / 市值 + 人工覆盖 | Layer 1–2 质量门槛、Layer 4 事件与估值 |
| 触发价格带是「开始看」的提示 | `BUY_CANDIDATE` 才可能真金白银 |

任何公司从 T1/T2 触发进入行动，都要回到 [`four-layer-screening-rules-v0.md`](four-layer-screening-rules-v0.md) 的 Layer 4 九条硬条件与硬性否决，本文件不构成买入授权。

## 7. 版本纪律

1. 改自动分档比例（`TIER_SHARE`）或触发带（`TRIGGER_DRAWDOWN`）必须在 `fdc/funnel.py` 顶部改并记版本号 + 受影响公司数；
2. 人工覆盖只追加 / 删除条目，不覆盖自动档位的历史；
3. `data/generated/funnel.json` 只能重算，不回写；
4. `UNAVAILABLE`（缺价）必须保留展示，不填假数据。
