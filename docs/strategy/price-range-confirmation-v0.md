# FDC 价格区间核定口径 v0

> 截止：2026-11-08 PST。字段含义及失效时保留 `N/A` 的方向已确认；Bear 损失、最低 Risk/Reward 与组合上限的数值门槛尚未冻结。本文不追认现有数值价带为已核定估值，也不授权交易。

## 1. 当前规则与字段的边界

- [AI 公司漏斗](ai-chain-company-funnel-v0.md)按重要性分 T1/T2/T3；52 周回撤只触发研究。T1 应有完整 dossier，T2 只有公司卡片，T3 明确“不做独立估值”。回撤幅度不能反推合理价。
- [四层筛选规则](four-layer-screening-rules-v0.md)要求核心公司的正常状态 dossier，并在具体事件后重新估算 Bear/Base/Bull、当前价格隐含的经营假设、价值损失和风险回报。约 30% 的 Base upside 是机会筛选，不是通用的 30% 买入折扣；其他买入数值门槛仍未冻结。
- FDC 的 `observation_range`、`entry_range`、`add_range`、`reduce_range` 是人工注释字段。API 只校验正数、成对端点和低价不高于高价；数据库没有方法、证据状态、估值日或版本字段。字段非空只表示“有人填了数”。
- `worth-buy-stocks` 的 ATR/均线交易计划价属于趋势与风控模型，不能代替 FDC 的企业价值估算。

## 2. 建议确认流程

1. **确定对象与时点。** 确认仍可独立交易的证券、普通股/ADS 单位、币种、收盘价交易日与来源，以及财报期间、提交日期和模型信息截止点。不同日期的报价、市值、股数不能直接混用。
2. **完成正常状态 dossier。** 记录业务驱动、客户/产品、竞争与可证伪 KPI；用 SEC/IR 原始文件核最近五年和最新季度的收入、利润、CFO、现金购建、股权薪酬、债务、现金、股份与重大或有义务。TTM 用“最近年报＋本年累计－上年同期累计”，不把单季或 backlog 机械年化。区分已实现数据、管理层指引与研究假设。
3. **建立股权价值桥。** 预测 3–5 年 Bear/Base/Bull 的收入、利润率、税、营运资本、资本支出和后续现金流；明确正常化而非只取最近 TTM。选用适合该业务的 DCF 或有出处的同口径相对估值，并交叉检查。处理限制现金、净债务、租赁、少数权益、融资与潜在摊薄；用估值时点的经济股数计算每股价值。股权薪酬须明确作为现金成本或稀释处理，避免重复扣算。
4. **反向验证与证伪。** 算出现价需要怎样的增长、正常利润率和现金转化；把这些要求与管理层指引、产能、订单兑现和可比公司相核。若市价与模型价值相距很远，解释差距来自可核增长、不同口径、融资/股数变化还是无法证实的预期；不得为了贴近现价调整倍数。
5. **独立复核与留痕。** 保存来源链接、期间、每一步算式、Bear/Base/Bull、估值日、失效条件和研究者/复核者分歧。原始估值快照追加保存，不覆盖旧版。新研究若缺关键输入、存在未解数据冲突或尚未完成独立复核，数值区间维持 `N/A`；已有历史草案先标注未核定、保留快照后再迁移。情景压力测试可写进研究记录，但不能冒充已核定价带。

## 3. 四个 FDC 字段的含义

| 字段 | 含义 | 写入门槛 |
|---|---|---|
| 观察 | 价格进入模型支持的正常状态价值附近，**启动重估**；不是 52 周回撤触发带，也不是目标价 | 完成正常状态 dossier、Bear/Base/Bull、股权桥和反向估值；说明区间与 Base/Bear/Bull 的映射 |
| 建仓 | 具体事件后，价格和基本面同时满足重估后的机会条件的**研究区**，不是自动买入价 | 除上项外，完成事件前质量冻结、Temporary/Structural 判断、更新后的 Bear/Base/Bull、约 30% Base upside、可承受的 Bear 损失和组合审查；尚未冻结的风险数值门槛未获确认前，不标作可执行建仓价 |
| 补仓、减仓 | 已持仓情况下的分批计划价 | 另核现有仓位、风险预算、事件后论点及组合敞口；缺失时留空 |

不同公司的价带可以远离现价；但必须有上述“现价隐含假设”的桥。T3 按现有漏斗规则只保留价格/新闻触发，除非正式提档并补完相应研究，不写独立估值区间。T2 不因卡片完成而自动获得建仓价。

## 5. 已确认口径与尚未冻结的门槛

1. **观察区只触发重估。** 不用统一折扣比例从 Base 值机械生成范围；每家公司的 dossier 必须列出 Bear/Base/Bull、观察带端点来源和失效条件。没有完整桥接时留 `N/A`。
2. **建仓区必须过事件后门槛。** 当前策略只有约 30% Base upside 的机会筛选；最大 Bear 损失、最低 Risk/Reward 与组合上限尚未正式批准。在这些门槛冻结前，已有 `entry_range` 只作为待审计的历史草案；新研究不写入已核定建仓数值。

AMD/NVDA 试点先保留原值并标注未核定，不把静态现金流压力测试升级为正常价值。待前瞻模型、独立复核和风险门槛完成后，再决定更新或清空；其余记录按 T1 核心、T2、T3 的研究深度逐批审计，每批先保留旧快照。
