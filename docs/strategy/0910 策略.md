# 0831 策略更新及思考过程解释

看完这几张图以后，我基本可以把你朋友这套“颜色系统”的逻辑逆向还原出来。

## **先说结论**

这套东西本质上不是一个“红=卖、绿=买”的交易模型，而是一个：

**Top\-down \+ Bottom\-up 的多维投资热力图。**

它把一只股票拆成：

**宏观环境 → 市场估值/风险 → 行业空间 → 公司护城河 → 财务增长 → 估值 → 未来趋势**

然后把每个指标统一转换成红—棕/黄—绿的视觉语言。

最重要的是：

**绿色不是“股票一定涨”，而是这个维度当前对持有/买入更有利；红色则表示这个维度更不利。**

最后真正决定“增持/不变/减持”的，看起来仍然是他本人综合判断，而不是Excel把颜色机械相加。

# **一、他的颜色有两套完全不同的生成方法**

这一点从你第一、第二张截图基本可以确定。

## **第一类：可以量化的市场数据——按历史 Min/Max 做归一化**

第二张图直接列出了：

- Short Min/Max

- Mid Min/Max

- Long Min/Max

第一张最下面又明确写着：

Min Value of a Past Period → Current Reading → Max Value of a Past Period

所以他大概率是在做类似这样的计算。

对于“越高越好”的指标：

Score=\\frac\{Current\-Min\}\{Max\-Min\}

然后：

- 接近历史最低 → 红

- 历史中间 → 棕/橙

- 接近历史最高 → 绿

视觉上就是：

**红 → 橙/棕 → 绿**

而且他会分别用不同时间窗口计算一次。

从 Note 可以看到，很多指标使用的是：

- Short：约1个月

- Medium：约3个月

- Long：约1年

但不同指标也不完全一样，比如Money Market Fund用了 `1M / 3M / 4.5M`。

所以这里的 **Short / Medium / Long 很可能并不是“准备持有多久”**。

而是：

**当前指标相对于不同历史观察窗口处于什么位置。**

这是一个很重要的区别。

# **二、有些指标会把颜色反过来**

截图里你可以看到很多：

`Note: Color Reversed`

原因很简单。

不是所有指标都是“越大越好”。

例如：

### **Fear \& Greed**

当前大概52。

如果市场非常贪婪：

对未来买入回报反而可能不利。

所以：

- Fear很高/Greed很低 → 可能偏绿

- 极度Greed → 偏红

因此需要 Reverse。

### **S\&P 500 / Nasdaq 高于20/50/200日均线的股票比例**

比例越高，意味着市场越全面上涨。

从趋势角度看可能是好事。

但如果他的模型把它理解为：

**市场是否已经过热、拥挤**

那么越高反而越红。

截图里这两项也明确标了 `Color Reversed`。

### **Buffett Indicator**

总市值/GDP：

越高意味着总体估值越贵。

所以也是：

数值越高 → 越红。

### **P/E**

同理。

在其他条件相同的情况下：

P/E越低 → 越绿。

所以他的系统实际上不是统一采用“数据越高越绿”，而是先规定：

**这个指标对未来收益而言，正方向到底是哪一边？**

然后再上色。

# **八、Forward这一列非常关键**

我觉得这是整张表里最值得你和晓飞借鉴的部分之一。

而是在比较：

**Current → Forward**

- EPS：54% → 17%

- Database share：16\.5% → 15%

- Data Center share：3% → 10%

- P/E：32 → 24

这实际上在试图回答：

真正赚钱往往不是因为：

而是：

**公司未来将比市场现在预期的更好。**

# **十二、但我认为他这套体系有几个比较明显的问题**

这个部分对你和晓飞尤其重要。

## **Min/Max着色方法很直观，但统计上比较粗糙**

例如过去一年某指标出现过一次极端值。

那么：

Min=10

Max=100

当前=50

颜色就完全受那一次100影响。

我更建议你们以后用：

**Historical Percentile**

比如：

- 0–20 percentile：红

- 20–40：偏红

- 40–60：中性

- 60–80：偏绿

- 80–100：绿

或者用winsorized Z\-score。

会比简单Min/Max稳定很多。

# **十三、更大的问题：有些东西并不是线性“越高越好/越低越好”**

比如Fear \& Greed。

极度恐慌：

可能是绝佳买点。

也可能是：

金融系统真的出了问题。

Credit Spread也是一样。

信用利差很低：

经济健康。

但也可能意味着：

市场过度乐观、风险补偿过低。

所以不能简单：

2\.7 = 绿

5 = 红。

很多市场变量其实是：

### **U型或者倒U型关系**

而不是线性关系。

这点如果你们以后程序化，一定不要简单复制他的Excel颜色公式。

---

# **十四、第二个问题：主观评分的“50%、75%、100%”容易制造虚假的精确感**

例如：

Microsoft Network Effect到底是50%还是65%？

这是没有客观答案的。

我反而建议你们以后使用：

- **Weak**

- **Moderate**

- **Strong**

- **Exceptional**

然后要求：

每一个评级必须附三条证据。

而不是假装“75%”有统计精度。

以后如果积累了100个公司案例，再逐渐把这些等级校准成数值。

---

# **十五、最重要的问题：他的表把四种不同概念混在了一种颜色里**

这里我特别建议你们不要完全照搬。

现在他的“绿色”可能分别意味着：

1. **公司质量高**

2. **增长好**

3. **价格便宜**

4. **市场环境有利**

5. **未来趋势改善**

6. **技术面不过热**

这六个“绿”其实意义完全不同。

比如：

Microsoft是一家非常好的公司。

这是 **Quality**。

Microsoft因为恐慌跌了30%：

这是 **Dislocation**。

下季度Azure可能超预期：

这是 **Catalyst**。

P/E跌到历史20 percentile：

这是 **Valuation**。

信用市场恶化：

这是 **Macro Risk**。

这五件事情不能混成一个“总绿度”。

# **十六、如果让我给你和晓飞设计，我会在他这个思路上升级一层**

你们只需要四个独立颜色模块：

### **① QUALITY — 这家公司到底有多好？**

更新频率：

每季度或者发生重大事件时。

包括：

- 护城河

- 市场空间

- 管理层

- 现金流质量

- 网络效应

- Switching Cost

- Pricing Power

- Balance Sheet

这部分非常稳定。

---

### **② DISLOCATION — 现在到底被错杀了多少？**

每天自动更新。

包括：

- 1D / 5D / 20D跌幅

- 相对行业ETF跌幅

- P/E压缩

- 盈利预测下降程度

- 股价下降与基本面下降的差值

- News narrative

这是你们最核心的一块。

---

### **③ CATALYST — 什么会让市场重新认识它？**

按事件更新：

- Earnings

- Guidance

- Product Launch

- 用户数据

- CapEx收益

- 分析师Revision

- 行业数据

- Regulatory event

核心不是“好公司”。

而是：

**为什么未来1—6个月市场会改变看法？**

---

### **④ RISK / POSITION — 即使判断正确，现在值得承担多大风险？**

包括：

- Macro

- Market breadth

- Volatility

- Portfolio correlation

- Single\-name risk

- Sector concentration

- Liquidity

这部分决定：

**买多少。**

而不是：

买不买。

## **所以，我对你朋友这套系统的评价**

**我认为它非常值得借鉴，尤其值得借鉴“把主观投资判断结构化并可视化”这个思想。**

它其实已经不是传统意义上的量化交易。

更准确说，它是：

**Discretionary investing 的半量化决策仪表盘。**

也就是：

**人负责理解世界，数据负责防止人只讲故事。**

这和你、晓飞真正适合做的方向是高度一致的。

但我不会让晓飞直接照着这张Excel复制。

**你们应该借它的“颜色语言”和多层结构，然后围绕你们自己的“优质公司错杀与估值修复”策略重新设计四套分数：Quality、Dislocation、Catalyst、Risk。**

如果这四套东西搭好以后，前面我们讨论的“700只股票怎么筛到30—50只白名单，再筛到每天5—10个真正候选”，基本就开始能够落到一个真正可操作的交易系统上了。
