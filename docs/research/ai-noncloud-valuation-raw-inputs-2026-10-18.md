### 计算桥（保持原报表精度）

- **NVDA，USD bn**：[FY2026 发布](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-fourth-quarter-and-fiscal-2026)给出 FY2026 收入/EBIT/CFO/购置/相关本金/FCF = `215.938 / 130.387 / 102.718 / 6.042 / 0.101 / 96.575`；[FY2027 Q2 发布](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2027)给出 FY2027 H1 = `177.837 / 117.270 / 74.421 / 4.434 / 0.092 / 69.895`，比较期 FY2026 H1 = `90.805 / 50.078 / 42.779 / 3.122 / 0.073 / 39.584`。各列按 `FY2026 + FY2027 H1 − FY2026 H1`；例如 CFO = `102.718 + 74.421 − 42.779 = 134.360`，FCF = `134.360 − 7.354 − 0.120 = 126.886`。公司定义 FCF 扣除了**物业、设备与无形资产购置及其相关本金支付**，不是只减 PP&E。相关本金不等同于完整的融资租赁本金披露。[10-Q](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000075/nvda-20260726.htm)称本期融资租赁成本不重大，但完整融资租赁负债/本金拆分 **[UNAVAILABLE]**。
- **TSM，TWD bn**：[2025 20-F](https://www.sec.gov/Archives/edgar/data/1046179/000162828026025362/tsm-20251231.htm) FY2025 收入 `3,809.0543`、EBIT `1,936.0917`、CFO `2,274.976`、CapEx `1,272.411`。2026/2025 Q1 收入 `1,134.103 / 839.254`、EBIT `658.966 / 407.081` 见[Q1 发布](https://www.sec.gov/Archives/edgar/data/1046179/000104617926000199/a1q26e_withguidancexfinal.htm)；Q2 `1,270.381 / 933.792`、`766.603 / 463.423` 见[Q2 发布](https://www.sec.gov/Archives/edgar/data/1046179/000104617926000451/a2q26e_withguidancexfinal.htm)；Q3 `1,494.243 / 989.918`、`876.445 / 500.685` 见[Q3 发布](https://www.sec.gov/Archives/edgar/data/1046179/000104617926000726/a3q26e_withguidancexfinal.htm)。故 TTM 收入 = `3,809.0543 + (1,134.103 + 1,270.381 + 1,494.243) − (839.254 + 933.792 + 989.918) = 4,944.8173`；EBIT 同式 = `2,866.9167`。现金流在演示稿 Q1/Q2/Q3 的单季数据分别为：2026 CFO `698.97 / 783.36 / 919.77`、CapEx `350.76 / 496.00 / 443.21`；2025 CFO `625.57 / 497.07 / 426.83`、CapEx `330.83 / 297.22 / 287.45`。来源：[2026 Q1](https://www.sec.gov/Archives/edgar/data/1046179/000104617926000199/a1q26presentatione008.jpg)、[2026 Q2](https://www.sec.gov/Archives/edgar/data/1046179/000104617926000451/a2q26presentatione008.jpg)、[2026 Q3](https://www.sec.gov/Archives/edgar/data/1046179/000104617926000726/a3q26presentatione008.jpg)；2025 比较期也在上述页及[2025 Q2](https://www.sec.gov/Archives/edgar/data/1046179/000104617925000082/a2q25presentatione_6kxwm008.jpg)。因此 TTM CFO = `2,274.976 + (698.97 + 783.36 + 919.77) − (625.57 + 497.07 + 426.83) = 3,127.606`；CapEx = `1,272.411 + (350.76 + 496.00 + 443.21) − (330.83 + 297.22 + 287.45) = 1,646.881`，FCF = `1,480.725`。演示稿定义 FCF = 经营现金流 − 资本支出；租赁本金是否包含于 CapEx **[UNAVAILABLE]**，不能和 NVDA 扣相关本金的 FCF 完全等同。
- **ASML，EUR bn**：[Q3 US GAAP 财表](https://www.sec.gov/Archives/edgar/data/937966/000162828026065813/financial_statementsxusx.htm)列示 2025 Q4 收入/EBIT/CFO/PP&E/无形资产购置 = `9.7181 / 3.4311 / 11.4103 / 0.4479 / 0.0225`，2026 9M = `29.7554 / 11.7868 / 11.3150 / 1.1151 / 0.1404`。相加得表中 TTM；本页统一现金差额 = `22.7253 − 1.5630 − 0.1629 = 20.9994`。Q3 财表的“debt and finance lease obligations repayments”合并披露，融资租赁本金无法单独提取，故此现金差额未额外扣租赁本金，和 NVDA 公司 FCF 不严格可比。

## 三、必须先处理的现金流失真与缺口

[ASML Q3 US GAAP 财表第 5、9 页](https://www.sec.gov/Archives/edgar/data/937966/000162828026065813/financial_statementsxusx.htm)：2026 Q3 CFO **€11.7976bn** 中“changes in assets and liabilities”单季**正贡献 €7.0090bn**；2025 Q4 同项正贡献 **€7.6407bn**。2026 前三季同项净贡献仅 **€0.2362bn**，所以截至 Q3 的 TTM 净贡献 **€7.8769bn**。单季 Q3 CFO 不能乘四，TTM €20.9994bn 现金差额也不能机械外推。作为**诊断而非正常化 FCF**，剔除报表“changes in assets and liabilities”整个行项目，TTM CFO 是 `22.7253 − 7.8769 = €14.8484bn`，再减两项现金购置为 **€13.1225bn**。该行可能含正常预收、交付与税项变动，整体剔除并非经济上正确的长期工作资本预测；预测仍需订单/交付/预收款逐期桥接。Q3 对应净收入 €4.9604bn，还包括权益投资相关收益/调整，不能将净利与 CFO 差额全归为营业质量改善。

完整股权桥仍缺 **TSM 与 ASML 最新期末的流动金融债务和租赁、ASML 最新期末在外股数、统一可比的融资租赁本金，以及估值日汇率**。以上保持 `[UNAVAILABLE]`；先确定这些输入及收入/资本强度假设，再建立 Bull/Base/Bear 预测。当前不能依据 TTM FCF 或美元股价直接给三家买入价/建仓档位。
