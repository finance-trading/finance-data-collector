## `monthly_summary.csv` 字段说明

每一行对应一个月数窗口。除交易日数字段外，名称以 `_pct` 结尾的字段单位都是百分比点，例如 `12.07` 表示 `12.07%`，不是 `0.1207`。除特别说明外，统计分母都是该窗口的 `observed` 事件，不包括右删失事件。

| 字段 | 含义 | 统计口径与解读 |
|---|---|---|
| `month` | 窗口月数 | 从反应日开始，到反应日加该月数的日历窗口。 |
| `recovered` | 曾经恢复事件数 | 窗口内至少有一个交易日收盘价严格高于财报前一日收盘价。 |
| `observed` | 可观察事件数 | 已经完整走完该窗口、且窗口内有有效收盘价的事件数。 |
| `recovery_rate_pct` | 曾经恢复率 | `recovered / observed`。回答“窗口内曾经恢复过多少”。 |
| `average_excess_pct` | 最高收盘超额平均数 | 每个事件先取窗口内最高收盘价相对目标价的超额，再对全部 observed 事件求平均；可以为负。 |
| `median_excess_pct` | 最高收盘超额中位数 | 上述最高收盘超额的 P50；为负表示至少一半事件的最高收盘价仍低于目标价。 |
| `recovered_average_excess_pct` | 已恢复事件最高收盘超额平均数 | 只对 `recovered` 事件计算，衡量成功事件曾经达到的平均幅度。 |
| `recovered_median_excess_pct` | 已恢复事件最高收盘超额中位数 | 只对 `recovered` 事件计算的 P50。 |
| `terminal_recovered` | 期末站稳事件数 | 窗口最后一个可观察交易日收盘价仍严格高于目标价的事件数。 |
| `terminal_recovery_rate_pct` | 期末站稳率 | `terminal_recovered / observed`。区别于曾经恢复率，衡量窗口结束时是否仍站在目标价上方。 |
| `recovery_trading_days_median` | 首次恢复交易日中位数 | 仅在已恢复事件中统计；从反应日开始计交易日偏移，反应日收盘即恢复记为 0。 |
| `recovery_trading_days_p25` | 首次恢复交易日 P25 | 已恢复事件首次收盘恢复速度的 25 分位数。 |
| `recovery_trading_days_p75` | 首次恢复交易日 P75 | 已恢复事件首次收盘恢复速度的 75 分位数；P25–P75 越宽，恢复速度差异越大。 |
| `excess_p25_pct` | 最高收盘超额 P25 | 全部 observed 事件最高收盘超额的 25 分位数，反映偏弱的一侧。 |
| `excess_p75_pct` | 最高收盘超额 P75 | 全部 observed 事件最高收盘超额的 75 分位数，反映偏强的一侧。 |
| `excess_p90_pct` | 最高收盘超额 P90 | 全部 observed 事件最高收盘超额的 90 分位数，用于观察右尾赢家。 |
| `terminal_average_excess_pct` | 期末超额平均数 | 窗口最后一个收盘价相对目标价的平均超额；负数表示平均而言期末仍低于目标。 |
| `terminal_median_excess_pct` | 期末超额中位数 | 窗口最后一个收盘价相对目标价的 P50；比最高收盘超额更接近“最终站稳”结果。 |
| `max_drawdown_average_pct` | 最大回撤平均数 | 每个事件从窗口内历史收盘高点到后续最低收盘价的最大跌幅，再求平均；通常为负。 |
| `max_drawdown_median_pct` | 最大回撤中位数 | 最大回撤的 P50；例如 `-28.60` 表示典型事件最大回撤约 28.60%。 |
| `pre_recovery_min_excess_median_pct` | 恢复前最低超额中位数 | 仅对发生恢复且恢复前存在交易日的事件，统计首次恢复前最低收盘价相对目标价的 P50；反映等待恢复期间的下行压力。 |
| `right_censored` | 右删失事件数 | `558 - observed`。数据截止日之前没有完整走完该窗口的事件，不当作失败。 |

若某字段没有足够样本，CSV 中会留空；这表示该统计不适用或没有可观察数据，不表示收益为 0。

## 口径

- 低开：首个反应交易日开盘价不高于前一交易日收盘价的 95%。
- 财报时点：`04:00–09:30` 视为盘前，`>=16:00` 视为盘后；其余时间不确定，排除。
- 每月窗口：从反应日（含当日）到反应日加 `m` 个日历月（含边界），`m=1..12`。
- 每日候选价：恢复统计只使用拆股调整后的日 `Close`，不使用日 `Open` 或日内 `High`，也不额外加入现金股息调整。
- 恢复：窗口内任意交易日 `Close > 财报前一日 Close`。
- 期末站稳：窗口最后一个可观察交易日 `Close > 财报前一日 Close`。
- 首次恢复速度：从反应日开始计数，首次 `Close > 财报前一日 Close` 的交易日偏移；反应日收盘即恢复记为 0。
- 最大回撤：窗口内收盘价相对此前收盘高点的最大跌幅。
- 权重：每个事件等权，不先按股票等权。

## 解释与限制

1. 这是当前 S&P 500 成分股中、事后筛出的十年赢家，存在强烈幸存者偏差和前视选择偏差。
2. Yahoo Finance 是第三方事件和价格来源，未逐一用发行人 IR/8-K 核验财报时间。
3. “超过”只表示某个交易日收盘价超过目标，不表示盘中或盘后可按该价成交。
4. 结果未扣交易成本、税费、滑点，也未扣除同期市场上涨。
5. 各月事件相互重叠，同一公司多次财报并非独立样本。
6. 当前快照未下载 SPY 或行业基准，也未附行业字段，因此相对基准和行业分组暂不可得。

## 结论

在 Yahoo Finance 可识别且有明确盘前/盘后时点的 **5,237** 个独立财报事件中，有 **558** 个事件的首个反应交易日满足“开盘价不高于前一交易日收盘价的 95%”。按事件等权、并对每个期限分别剔除右删失事件后：

| 恢复期限 | 恢复事件 | 可观察事件 | 恢复率 | 因期限未走完而右删失 |
|---:|---:|---:|---:|---:|
| 4 个日历月 | 374 | 529 | **70.70%** | 29 |
| 6 个日历月 | 402 | 513 | **78.36%** | 45 |
| 8 个日历月 | 418 | 493 | **84.79%** | 65 |

这表示“历史上曾经触及目标价”的比例，不表示可以按该最高价成交，也不表示这些股票现在值得买入。尤其是本样本先用完整十年结果筛出赢家，存在强烈的幸存者偏差与前视选择偏差；这些比例不能当成面向当时可投资股票池的无偏回测胜率。

## 精确定义与计算方法

1. **证券池。** 从 [`sp500-10y-total-return-screen-2026-09-25.md`](./sp500-10y-total-return-screen-2026-09-25.md) 的 135 个完整入选证券读取代码；GOOG 与 GOOGL 作为两个证券分别保留。
2. **财报事件与时点。** 通过 `yfinance 1.7.0` 抓取 Yahoo Finance 每个代码的 Earnings Calendar 页面（例如 [NVDA](https://finance.yahoo.com/calendar/earnings?symbol=NVDA&offset=0&size=100)）。所有时间统一为 `America/New_York`。共取得 5,323 行，移除 4 个“同一证券、同一时间戳”的完全重复行后，研究区间内有 5,319 条唯一的“证券-事件”记录；这不表示事件在统计上相互独立。
3. **时点分类。** `04:00 <= 时间 < 09:30` 视为盘前，反应日取公告当日或其后的第一个交易日；`时间 >= 16:00` 视为盘后，反应日取公告日期之后的第一个交易日。其余 82 个事件标为 `UNKNOWN` 并排除。09:30–16:00 的常规交易时段来自 [NYSE 官方交易时段](https://www.nyse.com/markets/hours-calendars)。
4. **价格。** 通过 Yahoo Finance chart 数据下载日频 `Open/High/Close`，参数为 `start=2016-09-22`、`end=2026-09-26`（结束日排除）、`auto_adjust=False`、`repair=False`。关闭 `auto_adjust` 是为了不把股息回溯调整混入开盘、最高与收盘价；Yahoo 返回的历史 OHLC 已按后续拆股重述。对 NVDA 2024-06-10 的 10:1、AAPL 2020-08-31 的 4:1 与 TSLA 2020-08-31 的 5:1 拆股点做了数量级抽查，拆股前后价格处于同一现行股数口径。`yfinance.download` 参数语义见其[官方 API 文档](https://ranaroussi.github.io/yfinance/reference/api/yfinance.download.html)；Yahoo [Adjusted Close 说明](https://help.yahoo.com/kb/SLN28256.html)明确该字段同时包含拆股和现金股息乘数，正是本研究没有把 `Adj Close` 因子应用到 OHLC 的原因。
5. **低开门槛。** 设反应交易日为 `t`，其开盘价为 `O_t`，前一交易日拆股调整后收盘价为 `C_(t-1)`：`gap = O_t / C_(t-1) - 1`。仅保留 `gap <= -5.00%` 的事件。
6. **恢复判定。** 对 `m = 4, 6, 8`，若从反应日 `t`（含当日）至 `t + m 个日历月`（含边界）之间任一日的拆股调整后 `High >= C_(t-1)`，则该期限记为恢复。使用日线最高价意味着只回答“盘中曾达到”，不要求收盘站回。
7. **右删失。** 只有 `t + m 个日历月 <= 2026-09-25` 的事件才进入对应期限分母。每个期限独立计算，因此分母从 529 降至 513、493。
8. **权重。** 每个合格财报事件权重相同；不是先求每只股票的平均值再等权。

计算环境为 Python 3.12、`pandas 3.0.5`、`numpy 2.5.2`、`yfinance 1.7.0`；数据抓取与计算日期为 2026-09-28。

### 与宽松口径的对账

计算复核中还测试了一个更宽松但未采用的版本：把所有 `>=09:30` 的时间都当作“盘后”，并使用含股息的 `auto_adjust=True` 总回报调整 OHLC。该版本会得到 562 个低开事件，以及 4/6/8 个月分别 `380/533 = 71.29%`、`411/517 = 79.50%`、`425/497 = 85.51%`。

本报告拒绝该版本有两个明确原因：

- 它额外纳入的 4 个低开事件都没有盘后时间证据：ON 2019-08-04 15:00（周日）、ON 2020-05-09 11:00（周六）、AMZN 2024-08-01 12:00、MCK 2024-08-07 12:00。把中午或周末的模糊时间机械视作盘后，不符合“无法确认时点则 `UNKNOWN`”的预先约定。
- `auto_adjust=True` 同时回溯调整拆股与现金股息，会改变跨除息日的价格目标和未来最高价。用户指定的是拆股调整后价格恢复，而不是含股息总财富恢复，所以主结果保留 Yahoo 的拆股重述 OHLC，并关闭额外的股息调整。

## 来源质量、限制与偏差

- **事件时点不是逐项第一方核验。** Yahoo Finance 是高覆盖率的第三方聚合源，不是发行人、交易所或 SEC；历史记录可能被更正，且页面不是不可变快照。本研究没有逐一查验 5,319 个发行人 IR 新闻稿或 8-K，所以所有财报时点应视为“Yahoo 提供的事件时点”，不是经过第一方审计的事实。82 个无法可靠分类的时间直接保留为缺口，没有猜测。
- **价格源同样是第三方。** Yahoo chart 数据便于同源复算，但不提供交易所级别的逐笔成交审计。拆股抽查只能证明样例口径一致，不能替代对全部公司行动的完整审计。
- **强前视与幸存者偏差。** 股票池由 2026-09-25 的当前 S&P 500 成分证券中“过去十年已经跑赢”的结果筛得；退市者、被剔除者、十年输家与历史不足者均不在样本内。因此结果通常会高估任意历史时点的可复制恢复能力。
- **证券并非独立样本。** 同一公司多季事件相关，GOOG/GOOGL 等同一发行人的多类别股份也被分别计数；简单事件比例没有做公司聚类标准误或发行人去重。
- **触及不等于可成交。** 日线最高价只证明盘中报价范围达到目标，不能证明有足够流动性按该价成交；结果未计买卖价差、滑点、税费与机会成本。
- **不是超额收益研究。** 目标是名义股价恢复到财报前收盘，不扣除 S&P 500 或行业同期回报，也不计股息。长窗口中的市场整体上涨会自然提高恢复率。
- **右删失和事件重叠。** 越长窗口的近期事件越多被剔除；若近期市场状态不同，4/6/8 个月比例并非只反映时间长度。一个证券的恢复窗口也可能跨越下一次财报。
- **代码与公司行动风险。** 当前代码可能包含改名、重组或前身证券历史。报告沿用原十年筛选的证券身份口径，没有重新构造逐日点时点身份映射。

## 可复核性结论

这是一份覆盖完整 135 证券的机械事件统计，适合回答“在当前十年赢家样本里，过去的财报低开曾在多长时间内回到财报前价格”。它不具备严格点时点投资回测所需的历史成分股、第一方逐事件时点、可交易成交模型和公司聚类推断，因此不应直接转化为“低开买入”规则或投资授权。
