# Watchlist 价格区间 + WatchItems 事件清单

核心思想：区间 = 估值锚点 V + 波动尺子 + 风险回报比 + 仓位上限；价格告诉你"便不便宜"，WatchItems 告诉你"为什么便宜、该不该买"。两者必须联动。

## 0. 开始前

- 向用户确认：股票代码、已有的估值或支撑位（如有）、账户总额与单票最大可承受亏损（默认 1%）、输出形式（对话表格 / Excel）。信息不全时先按默认值做，并在结果里标明假设。
- 现价、ATR、财报日、解禁日等时效性数据必须联网查询，不得凭记忆给出，并记录来源与查询日期。查不到的字段留空并标注"待补"。
- 用户若写"建仓 加仓 建仓"之类重复项，最后一项按"减仓/清仓"处理，并在回复里确认一次。

## 1. 估值锚点 V（三情景加权）

- 给出悲观 / 中性 / 乐观三个情景价，概率默认 25% / 50% / 25%：`V = 0.25×悲观 + 0.5×中性 + 0.25×乐观`。
- 单个情景价 = 预期 EPS × 目标 PE，或 FCF 折现。
- 技术面辅助：最近 6–12 个月关键支撑位、200 日线、前期平台，用来校验 V 是否离谱。
- 三情景价差距越大，说明不确定性越高，区间应压得越深。

## 2. 个股分级（决定折价深度和仓位上限）

| 级别 | 标准 | 单票上限 | 建仓折价 |
| --- | --- | --- | --- |
| A | 逻辑清晰、可验证、波动小 | 8% | 约 0.85V |
| B | 逻辑成立但有变量 | 5% | 约 0.75V |
| C | 主题或事件驱动 | 2% | 约 0.65V |

- 相关性上限：同板块合计不超过账户 20%。
- 波动大（ATR/价格 > 4%）区间拉宽，波动小则收窄。

## 3. 价格区间

| 区间 | 价格 | 动作 |
| --- | --- | --- |
| 观察区 | 建仓价上限 ~ 1.0V | 只盯盘，不动 |
| 预备区 | 离建仓区上沿 5% 以内 | 设价格提醒，复核 WatchItems |
| 建仓区 | 按分级折价，且满足风险回报比 | 首仓，占目标仓位约 1/3 |
| 加仓区 | 首仓价再跌 1~1.5×ATR(20)，或 0.7V~0.8V | 第二、三笔各约 1/3 |
| 失效线 | 跌破加仓区下沿，或逻辑被证伪 | 止损 / 重估 V |
| 减仓/止盈区 | 1.1V~1.2V 以上 | 分批减 |

- 风险回报比反推买价上限：要求 `(目标价 − 买价) ÷ (买价 − 失效价) ≥ 3`，则 `买价上限 = (目标价 + 3×失效价) ÷ 4`。
- 加仓间距用 1~1.5×ATR(20)，避免被正常波动洗出去；也可参考过去 3 年从高点回撤的 50% / 75% 分位。

## 4. 仓位反推

单笔仓位 = 账户总额 × 单票风险（默认 1%）÷ (入场价 − 失效价)，并受分级单票上限和板块上限约束，取最小值。

> 示例：V=100，建仓 85，加仓 75，失效线 68。首仓 85 买 1/3，75 再买 1/3，平均成本约 80，止损 68 约亏 15%，据此总仓位不超过账户 6–7%。

## 5. WatchItems（观察事件清单）

WatchItem = 一只票上一个值得盯的、可能改变 V 或改变操作的具体事件或指标。每条一行，独立成表，不要塞进主表。

### 5.1 事件分层

- 论点事件（能改 V）：财报、指引、关键经营指标、大客户订单、并购、解禁、增发、回购、管理层变动、政策与利率会议、竞品财报。必须预写达标线、证伪线和对应动作。
- 噪音事件（只影响情绪）：大盘波动、媒体观点。不改 V，只可能提供加仓机会，不建 WatchItem，除非用户要求。

### 5.2 字段

| 字段 | 说明 |
| --- | --- |
| ID | 如 NVDA-01，便于引用 |
| 代码 | 关联主表 |
| 事件名称 | 简短具体 |
| 类型 | 财务 / 公司 / 宏观 / 逻辑验证 |
| 日期或窗口 | 已确认日期，或预计窗口并标"预计" |
| 提醒日 | 事件前 3–5 天；财报则取前一周 |
| 影响（1–5） | 对 V 的影响程度 |
| 概率（0–1） | 发生或超预期的可能性 |
| 优先级分 | 影响 × 概率 |
| 达标线 | 如"营收增速 > 20%" |
| 证伪线 | 如"毛利率连续两季下滑" |
| 对 V 的影响 | 上调 / 下调 / 不变（达标与证伪各写一条） |
| 事件后动作 | 预设的"如果…就…" |
| 状态 | 待发生 / 临近 / 已发生待复盘 / 已复盘 / 归档 |
| 复盘结论 | 实际结果、V 是否更新、新 V |
| 来源与查询日期 | 日期类字段必填 |

### 5.3 规则

- 每只票保持 3–5 条活跃 WatchItem，只盯优先级分最高的前 2–3 条为重点。
- 事件发生后 24 小时内复盘：结果对比达标线与证伪线，判断 V 变没变；变了就重算整张区间，并回写主表的 V 和"最近 V 更新日"。
- 已复盘的条目保留不删，状态改为归档，便于回头检验判断准不准。
- 主表的"下次关键事件"只摘要该票最近一个未发生且优先级最高的 WatchItem，明细都在 WatchItems 表。

## 6. 事件与价格联动

| 情况 | 动作 |
| --- | --- |
| 进建仓区 + 相关 WatchItem 验证逻辑 | 按计划建仓 |
| 进建仓区 + WatchItem 证伪逻辑 | 不建，重估 V |
| 进加仓区 + 逻辑未变（纯情绪下跌） | 加仓 |
| 进加仓区 + 逻辑被破坏 | 不加，考虑止损 |
| 财报前一周内（状态为"临近"） | 不加仓，或首仓减半 |

## 7. 状态机与时间止损

- 票的状态：观察 → 预备 → 建仓 → 加仓 → 持有 → 减仓 → 退出。每次切换必须价格和逻辑同时满足。
- 时间止损：建仓后 2~3 个季度逻辑无进展，即使没破位也减仓。

## 8. 输出格式

三张表（Excel 则为三个工作表）：

1. **Zones 主表**，每只票一行：代码 / 级别 / 悲观价 / 中性价 / 乐观价 / V / 失效价 / 目标价 / 风险回报比 / 观察区 / 建仓区 / 加仓区 / 减仓区 / 单票上限 / 状态 / 最近 V 更新日 / 时间止损日 / 下次关键事件摘要。
2. **WatchItems 表**，字段见 5.2，一行一个事件。
3. **Calendar 事件日历**，按日期排序所有 WatchItem，标出提醒日。

若用户要 Excel：使用 `financial-analysis:xlsx-author` skill。输入单元格为三情景价、失效价、目标价、账户总额、各 WatchItem 的日期 / 影响 / 概率 / 达标线；V、买价上限、各区间价格、仓位、风险回报比、优先级分、主表的"下次关键事件"全部用公式自动计算；WatchItems 用代码与主表关联，日历按提醒日自动排序；输入与公式单元格用不同颜色区分，状态列用下拉选项，提醒日已到或已过期未复盘的行用条件格式高亮。
